# 麦子 AI 生图 · Windows 桌面版

双击打开 → 自动弹浏览器 → 首次填 API 密钥 → 直接生图。
所有数据都在你本机，密钥不会上传到任何第三方。

---

## 一、怎么用

### 方式 A：直接用（需要装一次 Python）

1. 安装 **Python 3**（[python.org/downloads](https://www.python.org/downloads/)），安装时**务必勾选 `Add Python to PATH`**；
2. 双击 **`启动(双击我).bat`**；
3. 浏览器会自动打开，第一次会要求填 **API 密钥**（在 [maizitech.xyz](https://www.maizitech.xyz) 控制台创建）；
4. 填好点「保存并验证」，通过后就能开始生图。

### 方式 B：打包成独立程序（推荐，给别人用也不需要装 Python）

1. 先按方式 A 装好 Python；
2. 双击 **`打包exe.bat`**，等 1~2 分钟；
3. 生成的 **`dist\共济生图\`** 整个文件夹就是独立程序——拷到任何 Windows 电脑，双击里面的 `共济生图.exe` 即可，**目标机器不需要装 Python**。

> **为什么是文件夹而不是单个 exe？**
> 单文件版（PyInstaller `--onefile`）运行时要把自己解压到 `%TEMP%` 再执行，这个行为模式和"释放型木马"高度重合，加上没有代码签名，很容易被杀软**误报成木马**。
> 文件夹版不自我解压，配合 exe 内的版本信息（发布者/产品名）与图标，误报率大幅下降。分发时把整个文件夹打成 zip 发出去即可。

## 二、密钥与校验规则

| 场景 | 行为 |
| --- | --- |
| **首次打开**（没有密钥） | 显示配置界面，必须填入有效密钥才能进入 |
| **之后每次打开** | 先在后台校验密钥：<br>· 有效 → 直接进入界面，无需重填<br>· **无效（401/403）→ 挡住界面**，要求重新配置正确密钥<br>· 平台连不上（超时/断网）→ 提示后仍可「先用上次配置进入」，避免网络抖动把人锁在门外 |

密钥保存位置：

```
Windows   %APPDATA%\maizi\config.json
macOS     ~/.maizi/config.json
```

界面右上角有 **设置密钥**（换 key）和 **退出**（关掉后台服务）两个按钮。

## 三、数据都在哪

| 内容 | 位置 |
| --- | --- |
| 配置（密钥、模型） | `%APPDATA%\maizi\config.json` |
| 生成记录 | `%APPDATA%\maizi\history.json` |
| 图片本地缓存 | `%APPDATA%\maizi\history\` |
| 参考图上传缓存 | `%APPDATA%\maizi\uploads.json` |
| 模型规格缓存 | `%APPDATA%\maizi\model_cache.json` |
| 运行日志（排查问题用） | `%APPDATA%\maizi\app.log` |

想换一份独立配置（比如多个账号），设置环境变量 `MAIZI_HOME` 指向别的目录即可。

## 四、常见问题

**双击没反应？**
先看 `%APPDATA%\maizi\app.log`。多半是没装 Python，或者装的 Python 没勾 `Add to PATH`。

**端口被占用？**
程序会自动改用其它空闲端口，不影响使用。若已有实例在跑，双击第二次只会再打开一次页面。

**图片生成了但记录里看不到图？**
生成记录会自动把结果图下载到本地；万一本地文件丢了，界面会自动改用平台链接显示，不会裂图。

**想清空所有数据？**
直接删掉 `%APPDATA%\maizi` 整个目录即可（下次打开会重新要求填密钥）。

## 五、文件说明（给维护者）

| 文件 | 作用 |
| --- | --- |
| `app.py` | 本地服务：托管界面、代理平台接口、保存密钥与记录（仅用 Python 标准库） |
| `index.html` | 界面：提示词 / 参考图 / 比例 / 分辨率 / 数量 / 生成记录 / 图片预览 / 密钥闸门 |
| `启动(双击我).bat` | 用系统 Python 直接运行 |
| `打包exe.bat` | 用 PyInstaller 打成一文件 exe（`--add-data index.html`） |

> 注意：`.exe` 必须在 **Windows** 上打包，PyInstaller 不支持跨系统交叉编译。
